# AI Governance Framework Generator

Generates tailored AI governance frameworks for Australian businesses,
aligned with the six AI6 practices in Australia's Voluntary AI Safety
Standard (NAIC Guidance for AI Adoption).

**This repository contains no source code.** The service is closed-source
and hosted at aiframework.com.au. This repo exists solely as a public
metadata pointer for MCP directory listings.

- Website: https://aiframework.com.au
- MCP endpoint: https://aiframework.com.au/api/mcp.php
- Transport: Streamable HTTP (stateless JSON-RPC 2.0, no auth)
- Tools: start_session, submit_answers, get_framework

Frameworks, not advice. See the website for full details.
